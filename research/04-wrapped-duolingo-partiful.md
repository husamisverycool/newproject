# 04: Spotify Wrapped, Duolingo, Partiful: source-only design dossier

Compiled 2026-10-07. This dossier contains no design opinions or suggestions. Every line reports what a source says.

## How to read this file

- **Research method.** All facts come from WebSearch result snippets and the search tool's summaries of them. No page could be opened directly, because WebFetch, Firecrawl, curl and browsers are blocked by the network lockdown.
- **Citations.** The search tool merges several results into one summary. Where a sentence could have come from more than one URL in a result set, every candidate URL is listed.
- **Search budget.** The shared per-turn WebSearch budget ran out after 37 searches. Several planned topics were never searched, so the Gaps section is long. More searches can run in a follow-up turn.
- **Confidence tags:**
  - **[multi]**: two or more independent sources, or separate searches, agree.
  - **[single]**: one source.
  - **[inferred]**: my interpretation. These are rare and labelled.
- **UNKNOWN** means no source found in this session states the value. Nothing is filled in from memory.
- **Brief-only claims are not confirmed.** Some claims appear only in the task brief: "3D lip buttons", "radius ~16px", the RSVP emoji 👍/🤔/😢 and the "These reminders don't seem to be working…" copy. No source found here confirms them. See Gaps.
